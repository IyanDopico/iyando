Una campaña de medida no empieza cuando se enciende el equipo. Empieza al decidir qué variable se quiere observar, qué condiciones se van a fijar y qué información contextual se debe guardar para poder interpretar los datos después.

La trazabilidad suele ser tan importante como el valor medido: hora, posición, orientación, configuración del equipo, versión del código y observaciones del entorno. Cuando esos datos faltan, el análisis posterior se vuelve frágil.

Una buena práctica es registrar cada sesión como una unidad reproducible: parámetros, fichero de datos, notas y resultados preliminares.
